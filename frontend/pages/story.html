📖 Story Explanation

Understand difficult concepts through simple examples.

Imagine a Computer as a School 🏫

Imagine your computer is like a school. The Operating System is like the principal who manages everything.

When a student starts doing an activity, it is like starting a program. That running program is called a process.

The principal decides which activity should get attention and which resources should be used.

Similarly, the Operating System manages CPU, memory, files and other resources.

So remember:

Operating System = Manager of the Computer 💻
