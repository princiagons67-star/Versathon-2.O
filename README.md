# Learn From Your Notes

## Versathon 2.0

An interactive learning application that helps students turn their study notes into active learning experiences.

Instead of simply reading notes, students can use their study material to learn, practice, test themselves, identify mistakes and improve.

## Core Idea

**Notes → Learn → Understand → Practise → Test → Analyse → Revise → Improve**

## Planned Features

- Student Login and Registration
- Student Profile
- Upload Study Notes
- Important / Exam-Focused Questions
- Flashcards
- Mind Maps
- Story-Based Learning
- Visual Explanations
- Practice Tests
- Easy, Medium and Hard Levels
- Timer
- Score and Performance Analysis
- Mistake Notebook
- Weak Topic Identification
- Revision Tracking
- Multilingual Learning
- Text-to-Speech
- Achievement Badges
- Student Dashboard

## Technology Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Backend API
- Database

### AI
AI-based features will be integrated for processing notes and generating learning content.
